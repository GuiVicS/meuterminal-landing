O problema

Mexer no servidor pelo celular costuma ser um sufoco.

Você só queria subir um ajuste, reiniciar um serviço ou olhar um log.

Faltam teclas

Apps de SSH espremem o terminal na tela. ESC, TAB, CTRL e setas ficam longe, e rolar a saída é ruim.

A sessão cai

O celular bloqueia, a conexão cai e o processo que estava rodando morre junto.

Você não vê o resultado

Ver o projeto rodando exige abrir portas ou fazer deploy. E o que o agente de IA abriu no servidor, você não enxerga.

O MeuTerminal resolve isso numa tela só.

Vibe coding sem computador

Seu ambiente de desenvolvimento mora na nuvem, não no aparelho.

Os agentes rodam no servidor. O celular é só a tela e o teclado. Troque de aparelho, perca o celular ou feche o app: o projeto e as sessões continuam onde estavam.

Agentes de terminal no bolso

O Claude Code já vem instalado. Codex e outros agentes de terminal também rodam. Peça, acompanhe e veja o resultado numa aba de navegador, tudo pelo celular.

iPhone e Android

Funciona no navegador ou instalado como app na tela inicial. Barra de teclas, comandos rápidos e ditado por voz deixam o terminal confortável na tela pequena.

O projeto não vai junto com o celular

Código, histórico, chaves SSH e login do Claude Code ficam em volumes no servidor. Entre em outro aparelho e encontre as mesmas abas, na mesma ordem.

Recursos

Feito para o celular

ESC, CTRL e setas onde seu dedo está.

Uma barra de teclas acima do teclado do celular, comandos salvos com um toque e ditado por voz.

ESCTABCTRLALT↑↓←→HOMEENDPGUPPGDN|/~-$&>

  • Comandos rápidos

    Salve comandos como “subir o projeto” e use com um toque. Eles ficam no servidor, iguais em todos os aparelhos. Cada um pode só digitar ou já executar.

  • Colar e histórico de copiados

    Um toque cola o que está copiado no celular. Segure para ver o que você copiou recentemente.

  • Ditado por voz

    Fale e o texto é digitado no terminal.

  • Gestos que fazem sentido

    Arraste com um dedo para rolar, inclusive dentro do vim ou do Claude Code. Toque com dois dedos para colar ou copiar tudo.

  • Instala como app

    Adicione à tela inicial (PWA) e abra em tela cheia. A interface se ajusta quando o teclado abre, e o modo foco esconde o resto.

Navegador embutido

Veja o projeto rodando, sem abrir portas.

Um navegador roda no próprio servidor: digite localhost:5173 e pronto.

  • As portas abertas são detectadas sozinhas e viram atalho para os projetos rodando.
  • Toque é clique, arrastar rola e o teclado do celular digita na página.
  • Veja no tamanho da aba, como celular (390×844) ou como desktop (1280×800).
  • Qualidade ajustável, com um modo leve para 4G.
  • Logins e cookies das páginas ficam salvos no servidor.

Arquivos e nuvem

Do servidor ao Google Drive, sem baixar nada.

Agentes de IA · MCP

Agentes que mostram o que fizeram.

Peça ao Claude Code para rodar o projeto. Ele mesmo abre a página na sua tela.

O MeuTerminal tem um servidor MCP próprio para os agentes que rodam nos terminais dele. O Claude Code já vem instalado na imagem Docker; Codex e outros agentes compatíveis com MCP também podem usar.

  • open_urlabre uma página numa aba de navegador para você ver.
  • screenshottira um print para o agente conferir o próprio trabalho.
  • read_pagelê o conteúdo da página aberta.
  • open_folderabre uma pasta no gerenciador de arquivos, inclusive do Drive.
  • notifymostra um aviso na sua tela, como “build pronto”.

O agente também consegue listar as abas e as portas abertas.

Exemplo: você pede ao agente “roda o projeto e abre no navegador pra eu ver”. Ele roda npm run dev, chama open_url com localhost:5173, confere com screenshot e avisa com notify. Uma aba nova com a página aparece sozinha no MeuTerminal.

Segurança e dados

Seu servidor, suas regras.

Proteções reais e dados que ficam com você. Sem promessas mágicas.

Login com 2FA

Email e senha, com verificação em duas etapas opcional por app autenticador (Google Authenticator, Authy, 1Password e outros). Tentativas erradas bloqueiam o login.

Sessões persistentes

Os terminais seguem rodando no servidor. Ao voltar, a tela e o histórico estão lá.

Dados em volumes

Home, configurações e banco do app ficam em volumes. Projetos, login do Claude Code, chaves SSH e histórico sobrevivem às atualizações.

Self-hosted

Nada passa por serviços de terceiros. Você controla o servidor.

MCP local com token

O servidor MCP só aceita conexões do próprio servidor, com token.

Arquivos isolados

Arquivos abertos no app são exibidos em modo isolado e não executam scripts.

Importante: o MeuTerminal dá acesso total ao servidor. Use senha forte, ative a verificação em duas etapas e publique sempre com HTTPS.

Instalação

Instale em poucos minutos.

Você precisa de um servidor Linux com Docker. Uma VPS comum serve.

bash 
git clone https://github.com/GuiVicS/meu-terminal.git
cd meu-terminal
cp .env.example .env   # preencha AUTH_EMAIL, AUTH_PASSWORD e BASE_URL
docker compose up -d --build

Depois, abra o endereço do BASE_URL no celular, entre e adicione à tela inicial. Dúvidas? Ler o guia.

  1. Crie um App a partir do repositório do GitHub GuiVicS/meu-terminal.
  2. Defina as variáveis AUTH_EMAIL, AUTH_PASSWORD e BASE_URL.
  3. Aponte o domínio para a porta 3000.
  4. Adicione volumes em /root e /app/data.

Os volumes guardam seus projetos e as configurações do app entre atualizações.
